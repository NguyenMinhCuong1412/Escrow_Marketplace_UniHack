# Historical Chat Inbox

Lưu các bản trích xuất từ các chat cũ tại đây. Mỗi file cần có:

- Tên/ID chat hoặc mô tả nguồn.
- Ngày trao đổi nếu xác định được.
- Nội dung do người dùng xác nhận.
- Đề xuất/giả thuyết do AI đưa ra.
- Quyết định đã chốt và bằng chứng.
- Mâu thuẫn hoặc câu hỏi còn mở.

Định dạng tên: `CHAT-YYYY-MM-DD-short-topic.md`. Không lưu secret, private key, seed phrase, token hoặc password.
