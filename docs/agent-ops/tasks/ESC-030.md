## Implementation constraints

- Đọc `AGENTS.md` rules 60 (UI/UX)
- Đọc `docs/specs/FRONTEND_SPEC.md` mục 3.1 (State enum) cho badge colors: Created=gray, AwaitingEvidence=blue, Attested=green/orange, Disputed=red, Resolved=emerald, Cancelled=gray
- Dùng `useReadContract` / `useWriteContract` / `useWaitForTransactionReceipt` (wagmi v2)
- Giá trị AVAX: contract dùng wei (uint256), UI hiển thị AVAX (chia 10^18)
- Nonce từ contract là `bytes32` hex — hiện nguyên không cắt
- Mỗi trade chỉ cần iterate `getTrade(i)` cho `i = 1..nextTradeId-1`, filter theo seller/buyer === connected address
