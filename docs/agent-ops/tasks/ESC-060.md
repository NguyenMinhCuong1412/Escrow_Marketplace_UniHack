## Acceptance Criteria

- [ ] AC-01: **Happy path** pass — Seller tạo trade → 2 bên deposit → seller chụp ảnh có nonce → buyer quay video có nonce → submit evidence → AI verify → risk < 50 + không flagged → resolveClean → hoàn cọc + reputation +1
- [ ] AC-02: **Fraud path** pass — Buyer gửi video KHÔNG có nonce (hoặc seller dùng lại ảnh cũ) → AI flagged + risk ≥ 80 → mở dispute → owner resolveDispute(violator) → phạt 5% + reputation -10
- [ ] AC-03: **Cancel unfunded** — chỉ 1 bên deposit → quá evidence window → cancelUnfunded → hoàn cọc bên đã deposit
- [ ] AC-04: **Withdraw pending** — nếu có pendingWithdrawals > 0, nút withdraw hoạt động
- [ ] AC-05: Finality Fuji < 5s cho mỗi transaction
- [ ] AC-06: Explainable Report hiển thị đúng: risk score, keypoint match image, nonce OCR result
- [ ] AC-07: Không có JS console error nghiêm trọng
- [ ] AC-08: Screenshots/recordings đủ cho slide + video
